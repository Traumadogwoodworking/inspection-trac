Architecture

Static front end. External backend. Clean operational separation.

Fast static delivery

The marketing site is exported as static HTML, CSS, and JS so it can be hosted anywhere without a runtime server.

Backend-managed truth

Authentication, permissions, report data, files, and routing remain on the external backend so the site stays thin and reliable.

Scoped access

Facility and organization scoping is enforced in the backend, with the portal acting as the browser entry point.

Operational reliability

The site is designed for clear access into the portal, not for handling durable business data itself.
